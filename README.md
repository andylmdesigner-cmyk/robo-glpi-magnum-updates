# Robô GLPI Magnum — atualizações

[Baixar 4.0.0-alpha.5 para Windows x64](https://github.com/andylmdesigner-cmyk/robo-glpi-magnum-updates/releases/download/v4.0.0-alpha.5/Robo-GLPI-Magnum-4.0.0-alpha.5-Windows-x64-Setup.exe).

Primeira instalação manual. Depois, ao abrir, o aplicativo consulta novas versões e mostra um aviso. Baixar e instalar exige sua confirmação; você pode escolher Agora não. Consulta manual em Sistema e suporte.

Não apague `%LOCALAPPDATA%\Magnum\RoboGLPI`: guarda configurações, rascunhos e histórico.

Pacote completo (~597 MB), sem delta. Sem certificado Authenticode. GLPI da empresa e Windows do funcionário ainda requerem teste acompanhado.

Este repositório distribui instaladores e informações de versão. Não publique documentos, credenciais ou chaves privadas aqui. O código-fonte é mantido separadamente.
